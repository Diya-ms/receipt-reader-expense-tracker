# 🧾 Receipt Reader & Expense Tracker

An AI-powered web application that automatically extracts information from receipts using OCR technology and helps users track, categorize, analyze, and predict their expenses through an interactive dashboard.

## 🚀 Features

### Receipt Scanning
- Upload receipt images (JPG, PNG, JPEG)
- OCR-based text extraction
- Automatic detection of:
  - Store Name
  - Date
  - Total Amount
  - Purchased Items
  - Tax Information

### Expense Management
- Add, edit, and delete expenses
- Automatic expense categorization
- View expense history
- Search and filter expenses

### Dashboard & Analytics
- Total expense overview
- Category-wise spending analysis
- Monthly expense tracking
- Weekly spending insights
- Interactive charts and graphs

### AI-Powered Insights
- Spending pattern analysis
- Monthly expense prediction
- Budget recommendations
- Expense trend forecasting

### Export Functionality
- Export reports to CSV
- Export reports to Excel
- Download expense summaries
